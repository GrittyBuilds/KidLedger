One-time setup — how to get a Google Client ID
  1. Go to console.cloud.google.com and create a project.
  2. APIs & Services → Enable APIs → enable Google Drive API.
  3. OAuth consent screen → External; add yourself as a Test user.
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Add your site to Authorized JavaScript origins (e.g. https://YOURNAME.github.io).
  6. Copy the Client ID, paste it above, click Connect.
